# Yoté —— 西非跳吃棋

终端版 Yoté（西非传统双人棋），纯 Python 标准库实现。

## 玩法

- **棋盘**：5×6，30 格；每方 12 枚棋子（● 你 / ○ AI）。
- **布子阶段**：轮流在空格放 1 枚，放满 24 枚后进入走子阶段。
- **走子阶段**：每轮走 1 枚，正交走一格到空格。
- **跳吃**：跳过相邻敌子落到其后空格，吃掉被跳过的子；
  每次跳吃成功后**可再额外移除对方场上任意 1 枚子**（"买一送一"，Yoté 的标志性规则）。
- **胜负**：吃光对方全部棋子获胜；走子阶段轮到你却无合法走法判负。

## 用法

```bash
python -m yote                 # 人机对战（需要终端）
python -m yote --auto --games 10 --seed 42   # AI 对 AI 自动演示
```

走子输入格式：`起行 起列 落行 落列`，如 `2 1 2 3`；
跳吃后的额外移除按提示输入对方棋子坐标。

## 已知局限（诚实版）

- AI 只是"有跳吃必跳、否则随机"的贪心策略，不做深层搜索；熟悉规则的人类通常能赢。
- 跳吃+额外移除让对局偏短（演示中 11–46 步收官），这是规则本身的高杀伤特性。
- 只有双人对战，无存档、无悔棋、无图形界面；Python 3.10+。
